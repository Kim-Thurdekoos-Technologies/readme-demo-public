# readme-demo-public

Demo repository for the OpenProject GitHub integration.

This repository and [`openteams-ai/readme-demo-private`](https://github.com/openteams-ai/readme-demo-private) sit in two different GitHub
organisations, and both feed one OpenProject project:
[OpenTeams-README](https://openproject.openteams.ai/projects/openteams-readme).

## Quick start

1. Open a pull request.
2. Mention the work package in the PR description as `OP#<id>`, for example `OP#116`.
3. The pull request appears in that work package's **GitHub** tab, with its state and
   checks, and the GitHub Bot adds a comment to the work package.
